### Niri WM 操作指南 (2026 CELL 实验室版)

#### 1. 窗口与画卷导航

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Mod + H / L` | 轨道滑动 | 在无限水平画卷中左右穿梭 |
| `Mod + J / K` | 垂直切换 | 在垂直堆叠的工作区间切换 |
| `Mod + Tab` | 窗口预览 | 查看所有窗口并跳转 |
| `Mod + S` | 窗口 Recall | 快速跳转至前一窗口 |

#### 2. 工作区交互与布局控制

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Mod + Page_Down / Up` | **聚焦切换** | 在当前工作区内上下切换窗口焦点 |
| `Mod + Shift + Page_Down / Up` | **窗口移动** | 在当前工作区内上下移动窗口位置 |
| `Mod + Home / End` | **视口跳转** | 快速跳转至工作区起点或终点 |
| `Mod + Plus / Minus` | **高度缩放** | 调整窗口高度 (Zoom In/Out) |
| `Mod + [ / ]` | **宽度缩放** | 调整窗口宽度 |
| `Mod + Z` | **最大化** | 列全屏 (Maximize Column) 切换 |
| `Mod + V` | **预设循环** | 在 0.3 / 0.6 / 0.9 宽度比例间循环 |

#### 3. 应用程序启动与管理

| 快捷键 | 目标程序 | 备注 |
| --- | --- | --- |
| `Mod + Return / T` | **Ghostty** | 高性能渲染终端 |
| `Mod + Space / W` | **Firefox** | 默认浏览器 |
| `Mod + BackSpace / F` | **Nemo** | 文件管理器 |
| `Mod + Escape / E` | **Zed** | 核心编辑器 |
| `Mod + D` | **Evince** | 文档/PDF 阅读器 |
| `Mod + X` | **xfce4-appfinder** | 通用应用启动器 |
| `Mod + Shift + C` | **关闭窗口** | 快速销毁当前窗口 |

#### 4. 工作区定点跳转 (Workspace)

| 快捷键 | 功能 | 映射 (1 - 4) |
| --- | --- | --- |
| `Mod + n/i/o/u` | 切换工作区 | 聚焦至指定工作区 |
| `Mod + Shift + n/i/o/u` | 移动窗口 | 将窗口移至指定工作区 |

#### 5. 系统集成与电源管理

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Print` | 截图控制 | 配合 Ctrl/Alt 组合使用 (全屏/窗口) |
| `Mod + P` | 快捷键备忘 | 覆盖显示当前所有绑定 |
| `Mod + Ctrl + Grave (~)` | **系统锁屏** | 调用 Swaylock |
| `Mod + Ctrl + Shift + Grave` | **系统休眠** | 执行 Suspend |
| `Mod + Ctrl + R` | 重载配置 | 应用 `config.kdl` 修改 |
| `Mod + Ctrl + Q` | 会话退出 | 结束当前 Niri 会话!!! |

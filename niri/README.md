# Niri 工作空间使用指南 (2026 CELL 实验室版)

### 1. 核心导航与跳转 (Infinite Strip)

Niri 的核心逻辑是无限水平滑动的“画卷”，配合 CELL 布局实现 100% 视口聚焦。

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Mod + Tab` | **窗口切换** | Preview所有窗口并跳转（方向键导航） |
| `Mod + S` | **窗口选择** | 从窗口列表中选择 (Rofi Show 模式) |
| `Mod + H / L` | **轨道滑动** | 在无限水平画卷中左右穿梭（支持方向键） |
| `Mod + J / K` | **工作区切换** | 在垂直堆叠的工作区间切换（Down/Up） |

---

### 2. 应用程序启动 (R&D 核心套件)

保留了 i3wm 的肌肉记忆，并针对现代工具链进行了优化。

| 快捷键 | 目标程序 | 备注 |
| --- | --- | --- |
| `Mod + Return` / `T` | **Ghostty** | 高性能渲染终端 |
| `Mod + Space` / `W` | **Firefox** | 默认浏览器 |
| `Mod + Escape` / `E` | **Emacs** | R&D 核心编辑器 |
| `Mod + BackSpace` / `F` | **Nemo** | 文件管理器 |
| `Mod + D` | **Evince** | PDF/文档阅读器 |
| `Mod + X` | **Rofi** | 应用启动器 (Run 模式) |

---

### 3. 轨道与窗口管理

基于平铺逻辑，管理窗口在画卷上的物理顺序。

- **调整窗口顺序**：`Mod + Shift + H / L`（像搬动幻灯片一样在轨道上调整位置） 。
- **跨区移动窗口**：`Mod + Shift + J / K`（将窗口带入上下工作区） 。
- **全屏与布局**：
    + `Mod + Z`：**最大化**切换（Maximize Column） 。
    + `Mod + V`：**预设宽度切换**（可在 0.3/0.6/0.9 比例间快速循环） 。

- **关闭窗口**：`Mod + Shift + C` 。

---

### 4. 工作区快捷映射 (n/i/o/u 逻辑)

延续自定义高效键位，覆盖核心工作流程。

| 快捷键 | 目标工作区 |
| --- | --- |
| `Mod + n / i / o / u` | 切换到工作区 **1 / 2 / 3 / 4** |
| `Mod + Shift + n / i / o / u` | 将窗口移至工作区 **1 / 2 / 3 / 4** |

---

### 5. 系统控制与维护

- **多媒体控制**：支持键盘多媒体键直接调节音量 与亮度 。
- **截图**：`Print` 键直接调用 Niri 原生截图 。
- **电源管理**：
    + `Mod + Ctrl + Grave`：**锁屏** (Swaylock) 。
    + `Mod + Ctrl + Shift + Grave`：**系统休眠** (Suspend)。

- **重载配置**：`Mod + Ctrl + R`（执行平滑过渡并重新加载配置文件） 。
- 显示快捷键：`Mod + P` 。
